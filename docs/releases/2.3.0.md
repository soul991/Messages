# Messages 2.3.0

Release 2.3.0 incorporates Indian DLT commercial sender categorization, telephony delta sync, RCS tapback badges, and rich offer cards from pull request #54.

## Changes

- **Telephony Delta Sync**: Added `TelephonySyncManager` with a `ContentObserver` watching SMS and MMS content URIs. Runs debounced delta syncs on app resume, permission grants, and default SMS role transitions, indexing only messages above high-water mark IDs.
- **Commercial DLT Senders & Transactional Guard**: Added `COMMERCIAL_ENTITIES` dictionary for Indian DLT commercial senders. Commercial promotional messages route to `Category.PROMOTIONS`. Included a transactional guard ensuring order, banking, recharge, ticket, and OTP messages remain in `INBOX` with notifications enabled.
- **RCS Tapback Reactions**: Added `RcsReactionParser` to parse incoming mirrored RCS tapback messages, correlate them with original message text, and display floating emoji badges on message bubbles.
- **Rich Offer Cards**: Added `OfferExtractor` and Material3 `OfferCard` to detect promo discounts, validity, and coupon codes from commercial SMS and present structured actionable cards in chat.
- **Security & CI**: Updated accepted advisories and scan retry handling for build-time dependencies, and upgraded Gradle action tooling.

## Verification

- Dependency vulnerability scan reports zero findings over threshold against the OSV database.
