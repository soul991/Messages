# Messages 1.6.1

This update improves conversation-list accessibility and respects reduced-motion preferences during swipe actions.

- TalkBack custom actions expose the configured conversation swipe actions without requiring a gesture.
- Action labels reflect the conversation's current state, including pin/unpin, mute/unmute, and read/unread.
- Swipe feedback uses the shared motion specifications, which switch to immediate transitions when Android animations are disabled.

Built from the current active working tree. Existing local scorer evaluation and public-distribution release gates remain as documented in `docs/reviews/1.6.0-product-audit.md`.
