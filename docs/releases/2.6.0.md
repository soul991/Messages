# Messages 2.6.0 (versionCode 34)

Release 2.6.0 introduces a comprehensive macOS and Mac WhatsApp-inspired Liquid Glass design language across the application, transforms outgoing sent message bubbles from high-glare neon green into a soothing, WCAG AAA-compliant forest emerald palette, retires legacy swipe customization settings in favor of an ergonomic dual-side swipe-to-reveal gesture system, integrates WhatsApp-style diagonal pushpin indicators across all thread and chat surfaces, and achieves verified 120Hz frame timing performance on real Android 16 hardware.

---

## 1. Soothing Sent Message Bubble Palette & WCAG AAA Contrast

### Motivation & Visual Changes
- **Problem**: Outgoing messages previously used a high-glare neon green (`#30D158`/`#34C759`) background with harsh black text, creating eye strain and visual fatigue in prolonged messaging sessions.
- **Solution**: Replaced the neon banner with a calming, nature-inspired forest emerald palette crafted specifically for long-form readability and optical harmony with the Messages theme.

## 2. macOS & Mac WhatsApp Liquid Glass Design Language

### Dual-Side Swipe-to-Reveal
- **Left-to-Right Swipe (Swipe Right)**:
  - **Read / Unread Tile**: Emerald green liquid glass tile (`SwipeIcons.UnreadBubble`) dynamically toggling conversation read state.
  - **Pin / Unpin Tile**: Smoked glass tile (`SwipeIcons.PinFilled`) toggling thread pinned state.
- **Right-to-Left Swipe (Swipe Left)**:
  - **More Options Tile**: Smoked glass tile (`SwipeIcons.MoreDots`) opening the Mac WhatsApp floating context sheet.
  - **Archive Tile**: Emerald green liquid glass tile (`Icons.Outlined.Archive`) archiving the conversation.
- **Zero-Latency 120Hz Animation**: Synchronous live drag offsets and edge-anchored `graphicsLayer` rendering eliminate per-frame layout passes and coroutine churn.

### Mac WhatsApp Floating Context Sheet (`LiquidGlassSheetDialog`)
- **Outer Shell**: Floating dark charcoal glass container (`#161719` dark / `#F2F2F5` light) with smooth 26dp rounded corners and specular highlight rim (`liquidGlassRimBrush`).
- **Android 12+ Live Backdrop Blur**: Applies OS-level `FLAG_BLUR_BEHIND` window blur (`blurBehindRadius = 48`) via `DialogWindowProvider` for authentic macOS translucent depth.
- **Contact Header**: Clean circular avatar and bold contact name vertically centered without subtitle clutter, matching Mac WhatsApp.
- **Grouped Inner Cards**: Concentric 18dp rounded cards (`#303034` dark elevated charcoal / `#FFFFFF` light) with 0.5dp `#464648` hairline dividers and 24dp crisp line icons:
  - **Group 1**: Mute / Unmute, Contact info, Mark as read / unread, Pin / Unpin.
  - **Group 2**: Block `<Contact Name>` (coral red `#FB5061`), Delete chat (coral red `#FB5061`).

### Liquid Glass System Primitives
- `LiquidGlassSurface`: Reusable glass surface supporting Live Haze blur or standalone modal surfaces with directional specular catch-lights.
- `LiquidGlassIconButton`: 48dp accessible touch target with 40dp floating glass visual disc, specular rim light, and spring press feedback.
- `GlassTopBar`: Floating Liquid Glass top navigation bar across Home and Chat.
- `BottomDock`: Modernized with persistent active pill and cached graphic layer draw passes.

## 3. WhatsApp-Style Diagonal Pinned Message Indicator

- **Pushpin Indicator**: Added a 45°-rotated pushpin icon (`SwipeIcons.PinFilled` / `Icons.Filled.PushPin`) indicating pinned status across:
  1. `HomeScreen.kt`: Trailing metadata row of conversation snippet.
  2. `SearchPane.kt`: Trailing metadata row of matching conversations.
  3. `ArchivedScreen.kt`: Trailing metadata row of archived threads.
  4. `ChatScreen.kt`: Top-level pinned message indicator banner and bubble indicator.
- **Visual Design**: 16dp compact vector rotated 45° in neutral muted text color (`MaterialTheme.colorScheme.textMuted`), instantly recognizable without text clutter.

## 4. Settings Simplification: Removal of Archive Shortcut
