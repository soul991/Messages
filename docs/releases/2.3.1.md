# Messages 2.3.1

Release 2.3.1 contains fixes for folder navigation, touch handling during transitions, and dock interaction from pull request #57.

## Changes

- **Folder Navigation on Return**: Returning from a conversation no longer resets the Home folder to the launch folder (`onFolderConsumed` clears the initial navigation request once handled).
- **Folder Transition Touch Handling**: Taps on the outgoing folder pane are ignored during folder transitions, and the incoming pane draws on top (`targetContentZIndex = 1f`).
- **Folder Animation Order**: The `FOLDERS` animation sequence now matches the dock order (`Review` before `Spam`).
- **Dock Interaction**: The dock drag gesture was removed; tab selection is tap-only. The lift-and-glide animation remains active for tab switches.

## Known Limitations

- Dock behaviour and folder transitions were verified by screen recording review and manual use only; there are no automated UI tests for them.
