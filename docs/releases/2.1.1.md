# Messages 2.1.1

## Removed
- Automatic synthetic data injection on application startup.
- Synthetic stress data generator (`SyntheticStressData.kt`).
- Reaction storage (`ReactionStore.kt`).
- Reaction overlay UI and interaction components in chat.
- Thread ID 100 conditional routing in chat screen.

## Cleanup
- Executes a one-time maintenance query on application startup guarded by `cleanup_synthetic_v1` in `settings` preferences.
- Deletes rows matching `threadId == 100 AND address == "+1 (555) 019-2834" AND smsId BETWEEN 900001 AND 900100`.
- Deletes the `message_reactions` shared preferences file.
- Does not modify other rows, threads, or system telephony records.
