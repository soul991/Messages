# Messages 1.6.0

This release advances the current Messages app with the preserved UI, accessibility, motion, messaging, and protection work in the active source tree.

- Refines home and chat presentation, shared animation behavior, contact details, labels, and status/time formatting.
- Keeps filtering local and reversible; the optional on-device scorer remains opt-in and is not presented as validated across languages.
- Hardens update download boundaries and removes message-derived content from selected receiver/classification failure logs.
- Keeps the current Android default SMS/MMS role and shared telephony message store.

The local signed APK was built from the active working tree. The source tree still has in-progress model evaluation; complete that evaluation, finish the privacy-policy publisher/contact/date fields, and resolve the Android Gradle Plugin 8.5.2 / compileSdk 35 warning before public distribution.
