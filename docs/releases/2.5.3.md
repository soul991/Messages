# Messages 2.5.3 (versionCode 33)

Release 2.5.3 restores the floating glass "Go to top" navigation button across all conversation lists, establishes verified instrumented accessibility contrast compliance (WCAG AA), confirms rapid touch event registration and low dispatch latency on real Android environments, provides exact Xiaomi notification icon verification guidance, records jank and back-gesture performance metrics, and catalogs all features removed since v2.3.1.

---

## 1. Restored "Go to Top" Glass FAB (Job 2)

### Architecture & Design
- **Visuals & Shape**: Restored the jump-to-top button originally introduced in commit `b0806c9` and modernized into Messages' 2.5.2 real backdrop blur design language (`design-system/src/main/kotlin/com/messages/designsystem/JumpToTopButton.kt`).
- **Geometry**: Compact circular footprint (44dp visual diameter, 48dp touch target) using `CircleShape`.
- **Placement**: Anchored at `bottom-start` with 16dp edge margin and elevated 88dp above the bottom navigation dock. It strictly avoids overlapping the New Message FAB (anchored at `bottom-end`), the bottom dock (centered), transient snackbars (elevated above dock), or conversation row text.
- **True Backdrop Glass**: Powered by the Haze blur engine (`HazeStyle` with 22dp blur radius, 72%+ dark tint `0xD11C1C1F`, 1dp hairline border `0x26FFFFFF`, subtle top highlight `0x14FFFFFF`). Below API 31, gracefully degrades to solid near-opaque dark surface.
- **Icon & Contrast**: Features `Icons.Filled.KeyboardArrowUp` in neutral text tone (`#F2F2F4` in dark mode, `#111113` in light mode), delivering **15.21:1** contrast against dark glass (well exceeding WCAG 3.0:1 requirement for essential icons).

### Behavior & Coverage
- **Visibility Spring**: Springs into view via `scaleIn()` and `fadeIn()` (`Motion.screenSpring()`) when scrolled past item threshold (`firstVisibleItemIndex > 6`). Hides automatically when returning near top (`firstVisibleItemIndex <= 6`).
- **Interaction**: Tapping smoothly scrolls list to position 0 (`animateScrollToItem(0)`) and restores the collapsing search bar header (`searchBarOffsetPx = 0f`).
- **Screen Coverage**: Wired into:
  1. `HomeScreen.kt` across all category tabs (Personal, Promotional, Spam, Review, Blocked).
  2. `HomeScreen.kt` search results view (`SearchPane`).
  3. `ArchivedScreen.kt` for long archived message archives.
  4. `TrashScreen.kt` for soft-deleted message lists.
- **Verification**: Unit tested in `app/src/test/kotlin/com/messages/app/ui/home/JumpToTopVisibilityTest.kt` (4 passing test cases).

## 3. Accessibility Contrast Compliance Audit (Item 5)

Implemented and verified Google Accessibility Test Framework (ATF) ColorContrastCheck algorithm based on W3C WCAG 2.1 relative luminance standards via instrumented test `app/src/androidTest/kotlin/com/messages/app/AccessibilityContrastInstrumentedTest.kt`:

- **Dark Mode Primary Text (`#F2F2F4` on `#000000`)**: **18.78:1** (WCAG AAA compliant, threshold 7.0:1)
- **Dark Mode Muted Subtitles & Timestamps (`#9898A0` on `#000000`)**: **6.44:1** (WCAG AA compliant, threshold 4.5:1)
- **Light Mode Primary Text (`#111113` on `#FFFFFF`)**: **17.57:1** (WCAG AAA compliant, threshold 7.0:1)
- **Light Mode Muted Subtitles & Timestamps (`#71717A` on `#FFFFFF`)**: **4.93:1** (WCAG AA compliant, threshold 4.5:1)
- **Dock Glass & Jump-to-Top Icons (`#F2F2F4` on `#1C1C1F` dark / `#111113` on `#FFFFFF` light)**: **15.21:1** dark, **18.86:1** light (WCAG Graphical Objects compliant, threshold 3.0:1)
- **Transient Snackbars (`#FFFFFF` on `#1C1C1E`)**: **17.01:1** (WCAG AAA compliant)
- **Financial Debit / Alert Badge Text**: **8.20:1** (WCAG AAA compliant)

**Screens Audited**: `HomeScreen`, `ChatScreen`, `NewMessageScreen`, `SearchPane`, `ArchivedScreen`, `TrashScreen`, `DashboardScreen`, `WhyFilteredScreen`, `NotificationSettingsScreen`, `SettingsHub`, `SettingsScreen`, `AboutScreen`, `AppLockScreen`, `DriveBackupScreen`.

## 6. Notification Icon & Xiaomi Hardware Testing Guide (Item 3)

### Changes Made in App
1. **Renamed Launcher Icon Resources**: Migrated from `@mipmap/ic_launcher` to `@mipmap/ic_launcher_v2` across all densities (`mdpi`, `hdpi`, `xhdpi`, `xxhdpi`, `xxxhdpi`) and XML vector configurations (`ic_launcher_v2.xml`, `ic_launcher_v2_round.xml`) to invalidate stale OEM icon caches keyed by resource name.
2. **Proprietary MIUI / HyperOS App Icon Extra**: In `MessageNotifier.kt`, added `applyXiaomiAppIcon()` which detects Xiaomi/Redmi/Poco devices (`Build.MANUFACTURER.equals("Xiaomi", ignoreCase = true)`) and attaches the `miui.appIcon` extra populated with `Icon.createWithResource(context, R.mipmap.ic_launcher_v2)`.

### How to Test on Physical Xiaomi Hardware
1. Install release APK:
   ```bash
   adb install -r Messages-v2.5.3.apk
   ```
2. Clear stale MIUI / HyperOS launcher icon cache (MIUI caches app launcher icons indefinitely across updates):
   - **Method A (No Root)**: Go to **Settings > Apps > Manage apps > System launcher > Clear data > Clear cache** (or switch MIUI Theme to Default and back).
   - **Method B (ADB command)**:
     ```bash
     adb shell pm clear com.miui.home
     ```
3. Trigger an incoming notification:
   - Send an SMS to the phone or run an incoming broadcast test.
4. Verify notification headers:
   - Inspect Heads-up banner and Lock screen: icon displays the clean new Messages logo rather than the old purple skin.
   - Run dumpsys to confirm extras:
     ```bash
     adb shell dumpsys notification --noredact | grep -A 10 "com.messages.app"
     ```
     Verify `extra: miui.appIcon` is populated.
