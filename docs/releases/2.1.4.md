# Messages 2.1.4

Release 2.1.4 completes the two owner orders from Round 5 regarding dock iconography and vault screen designs.

## Changes

- **Dock Iconography (Order O1)**: Redesigned all five tab icon pairs (Personal, Bank, Offers, Review, Spam - both Outlined and Filled) in Figma (frame `23:75`) following the Telegram design system stroke and geometry. Implemented new vector paths in `DockIcons.kt`. - **Vault Screen Designs (Order O2)**: Created Figma frames on page `Round5` (`21:73`) for all eight vault pages in both Dark and Light themes (16 frames total), anchored to Figma frame `1:305`: Setup Chooser (`24:108` / `25:323`), PIN Setup (`24:123` / `25:341`), Pattern Entry (`25:160` / `25:377`), Password Entry (`25:187` / `25:403`), Locked Space Home (`25:209` / `25:424`), Secret Compose (`25:225` / `25:440`), Secret Settings (`25:254` / `25:469`), and Why Screen (`25:288` / `25:503`). Exported 2x PNGs to `docs/reviews/round5/vault_figma/` and generated comparison sheets in `docs/reviews/round5/vault_compare/`.
- **Security Verification**: Verified that `FLAG_SECURE` is active on all vault screens, recents thumbnails are blank, logcat output contains no PIN or credential entries during user entry, core secret encryption logic in `core-messaging/src/main/kotlin/com/messages/core/secret` is unchanged, and clean-install and upgrade paths preserve vault credential verification.
