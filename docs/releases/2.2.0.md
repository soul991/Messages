# Messages 2.2.0

Release 2.2.0 incorporates the Orchid theme, the floating dock component, and bundled variable typography from pull request #50.

## Changes

- **Theme Palette**: Added Orchid as the default theme accent along with corresponding surface colours.
- **Theme Migration**: Users configured with the default theme or Violet accent are migrated to Orchid. Users with other explicitly chosen accents retain their existing selection.
- **Floating Dock**: Replaced the fixed bottom navigation bar with a floating dock. Implemented dock shape geometry, spring physics animations, drag gestures, and a reduced-motion fallback.
- **Bundled Typography**: Bundled the Inter variable font (`inter_variable.ttf`, 876,576 bytes) under `design-system/src/main/res/font/`. Open Font License notice is provided in `design-system/NOTICE`.
- **Test Coverage**: Added unit tests covering dock behavior and theme accent resolution.

## Known Limits

- **Border Contrast**: `outlineVariant` borders measure between 1.25:1 and 1.51:1 contrast against background surfaces, falling below 3:1. These lines are decorative hairlines.
- **Benchmark Measurements**: Benchmark runs were conducted exclusively on an x86 emulator, only 10 of 40 planned journey runs exist, and same-build noise is larger than any before/after gap. The data is inconclusive and no performance claims are made.
