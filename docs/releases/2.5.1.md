# Messages 2.5.1

Release 2.5.1 is a comprehensive stabilization, data integrity, and visual polish release for the Messages app following the 2.5.0 redesign. It resolves critical data protection issues, refines gesture navigation, unifies transient system messages, fixes notification badge caching on OEM skins, and completely eliminates legacy theme leftovers.

## Summary of Changes

### 1. Data Integrity & Protection (Phases 0 & A)
- **Automatic Permanent Delete Freeze**: Halted all automatic purging across `TrashRetention`, `SpamCleanup`, and `OtpCleanup`. No message is permanently deleted without explicit user approval.
- **Trash Integrity & Auto-Restore (`MIGRATION_11_12`)**: Upgraded Room database schema with `trash_reason` ("user" vs "auto-..."). Only deliberate user deletions now move messages to Trash. Added a safe "Restore all auto-trashed" action to recover previously misfiled messages.
- **Unconditional SMS Ingestion**: Hardened telephony broadcast reception (`SmsDeliverReceiver`) with `ReceiveAudit` pipeline logging across `RECEIVED`, `PARSED`, `CLASSIFIED`, `STORED`, and `DISPLAYED` stages. Ensured that malformed or alphanumeric sender addresses are never dropped.

### 2. Gesture Navigation & Screen Architecture (Phases B, C & G)
- **Collapsible Search Header (G1)**: Implemented a smooth nested-scroll connection on the Home list where the search bar scrolls away on downward scroll and reappears seamlessly when scrolling up or reaching the top, with zero list shift.
- **Unified Dark Transient Snackbar (G2)**: Replaced all legacy Snackbars and Toasts with `AppTransientSnackbar`: a high-contrast dark surface floating above the dock, featuring 4.5:1 text contrast, an instant 48dp dismiss (X) target, 1-second auto-dismiss for informational alerts, and a 4-second green Undo action.
- **System Back Gesture Navigation (G3)**: Corrected navigation back-stack behavior across `Blocked`, `Archived`, `Trash`, `Outbox`, `Protection`, `Why-Filtered`, `Locked Space`, Settings screens, and notification deep links, ensuring system back gestures return to Home instead of exiting the application. Verified via `NavigationBackPolicyTest`.
- **Edge-to-Edge System Bars (G4)**: Removed dark gradient scrims and top glass bar tints. Enabled edge-to-edge transparent system navigation and status bars so conversation content scrolls cleanly behind the glass dock.
- **Accidental Archive & Swipe Controls (C1–C4)**: Removed swipe-to-delete, introduced single-choice archive swipe preferences, added horizontal dominance gesture filtering to prevent diagonal accidental swipes, and updated swipe reveal backgrounds with dark confirmation banners.
- **Dock Polish (B1–B5)**: Standardized dock pill height to 56dp (64dp active tab), guaranteed persistent visibility, restored glass blur fallbacks, standardized FAB clearance to 88dp, and hardened list row long-press stability.

### 3. Classification & Misfiling Fixes (Phase E)
- **Sender Normalization (E1)**: Stripped regulatory 2-letter routing prefixes (e.g. `VK-`, `BZ-`), expanded commercial brand name dictionaries (banks, utilities, delivery services), and cleaned shortcode mapping.
- **Precision Spam Filtering (E2)**: Eliminated false positives on transactional updates and personal contacts while accurately intercepting urgent unknown sender lures, lottery/crypto scams, and aggressive marketing.

### 4. Settings & Accessibility (Phase D)
- **High-Contrast Settings Tiles (D1)**: Optimized icon tile containers (14% light / 24% dark) and glyph foregrounds to guarantee WCAG AA 4.5:1 contrast.
- **Visible Switch Tracks (D2)**: Added high-contrast borders and neutral fills for disabled/off switch tracks.
- **Protection Dashboard Neutral Hero (D4)**: Shifted dashboard hero card and avatar palettes to neutral dark surfaces.
- **Automated WCAG AA Verification Suite (D5)**: Added `SettingsContrastTest` and `FixedColorSchemesContrastTest` enforcing minimum 4.5:1 contrast on all UI text and surface pairs.

### 5. Notifications & OEM Compatibility (Phase N)
- **Dynamic Shortcut Cache Invalidation (N2)**: Resolved stale launcher badge rendering on Android SystemUI. On version upgrade cold start, all dynamic shortcuts are purged from `ShortcutManagerCompat` and republished with the redesigned green 'M' adaptive icon (`R.mipmap.ic_launcher`).
- **Notification Glyphs & Design Tokens (N3)**: Cleaned all notification sites (`MessageNotifier`, `Scheduling`, `AppUpdateManager`, `UpdateCheckWorker`) to strictly use `ic_stat_message`, `ic_notif_fraud`, and `ic_notif_reminder` with `#30D158` (accent green) and `#FF453A` (fraud red).
- **OEM Skin Documentation (N4)**: Documented Xiaomi HyperOS / MIUI 14 SystemUI behavior regarding proprietary blue/indigo overrides on action buttons in [`docs/audit/OEM_NOTIFICATION_BEHAVIOUR.md`](../audit/OEM_NOTIFICATION_BEHAVIOUR.md).
- **Automated Payload Tests & Screen Matrix (N5)**: Added `NotificationBuilderOutputTest` and verified a genuine 8-state screenshot matrix across heads-up, expanded shade, collapsed shade, and lock screen in both light and dark modes.

### 6. Legacy Asset Sweep (Phase S)
- Swept the repository to eliminate legacy multi-accent color names (`violet`, `purple`, `lavender`, `teal`), obsolete themes, and unused drawables (`ic_notif_review.xml`).
- Marked all historical documentation describing superseded UI themes with `> [!NOTE] SUPERSEDED` notices.
- **Preserved Feature**: Preserved the custom photo-wallpaper capability (`ChatStyle.photoFile()`) in `ChatStyle.kt` and `ChatScreen.kt`.
