# Messages 2.5.0

Release 2.5.0 introduces a comprehensive UI redesign of the Messages app with a dedicated fixed dark/light visual identity, modernized typography, floating glass navigation dock, revamped message selection and loupe, updated branding assets, and overhauled notification handling.

## Changes

- **Fixed Dark/Light Identity**: Replaced dynamic Material You and customizable color palettes with a crisp, high-contrast identity: pure black background (`#000000`) with vibrant green accent (`#30D158`) in dark mode, and an off-white background (`#F7F7F4`) with deep green accent (`#1E9A44`) in light mode.
- **Inter Typography**: Standardized typography on Inter across all screens, headings, conversation threads, and metadata elements.
- **Floating Glass Dock**: Introduced a frosted glass dock anchored above the bottom navigation bar featuring four categories: Personal, Promotional, Spam, and Review (with Bank merged into Personal). Dock icons display category-specific semantic accents in light mode.
- **Flat Chat List & Friendly Sender Names**: Streamlined the conversation list with sender name resolution that maps raw alphanumeric sender IDs (e.g., `AV-AIRTEL-S`, `VK-SBIINB`) to clean, recognizable service labels with raw IDs as fallback.
- **Tinted Bank Summary Cards & Anchored Menus**: Redesigned transaction and bank summary cards with subtle surface tinting, clear debit/credit balance chips, and anchored context menus for quick actions without clipping or overlapping adjacent content.
- **Order Status Extractor Accuracy**: Corrected the order summary classifier so order confirmation messages (e.g., "Order Placed: Hi ISTAK AHAMED...") are accurately identified as `placed` rather than prematurely flagged as `delivered`.
- **Selection Top Bar & Text Loupe**: Replaced default selection styling with a WhatsApp-style contextual top bar (item count, close button, delete/archive actions) and added an iMessage-style magnifying loupe with drag anchor handles for precise in-bubble text selection.
- **New App Logo & Adaptive Icons**: Deployed the new green speech bubble mark with cutout message lines across the app. Added adaptive launcher icons with dark background (`#000000`), monochrome themed icon support on Android 13+, and an optional user-selectable light icon alias (`#F7F7F4`).
- **Notification Overhaul**:
  - Notification channels aligned to category importance: Personal (High), Promotional (Low), Spam (Minimal/Silent), and Review (Default). The legacy Transactions channel is removed and cleanly migrated.
  - Automatic sender-based grouping with summary notifications to prevent notification drawer flooding.
  - Direct inline reply action on personal messages when reply recipient resolution is available.
  - One-tap "Copy code" smart action for detected OTP verification codes.
  - Lock-screen privacy toggle allowing users to mask message bodies on the secure lock screen according to their privacy preference.
  - Dedicated in-app notification settings linking directly to system channel settings.

## Changes for Existing Users

- **Appearance Customization Removed**: The dynamic color palette (Material You) and user custom color theme settings were removed in favor of the consistent fixed dark/light system identity.
- **Bank Tab Merged**: The standalone "Bank" category tab has been retired; all transactional messages now seamlessly reside within the "Personal" folder.
- **Transactions Notification Channel Retired**: The legacy "Transactions" notification channel was removed and automatically migrated into the "Personal" notification channel.

## Known Limitations

- **Android Versions Below 16 (API 36)**: Automated testing and UI verification were primarily conducted on Android 16 (API 36) emulator environments. Earlier OS versions (Android 8.0 - 15) rely on platform backward compatibility and Jetpack libraries.
- **Physical Device Testing**: Testing for this release was conducted in Android emulator environments; real-world verification on physical hardware has not yet been performed for this build.
