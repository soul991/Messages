# Messages 2.5.2

Release 2.5.2 is a targeted stability, performance, and visual refinement release for the Messages app following 2.5.1. It delivers true backdrop blur glass architecture, refined animations, accessibility contrast compliance (WCAG AA), notification badge cache invalidation, deduplicated transaction intake, improved conversation density, restored in-app brightness controls, and hardened protection against financial and crypto trading spam.

---

## Summary of Changes

### 1. Dock Architecture & True Backdrop Glass (Item 1)
- **Geometry & Hierarchy**: Standardized dock height to 62dp, corner radius to 31dp, navigation icons to 26dp, and tab labels to 12sp. Maintains a compact, centered, floating footprint always visible above list content.
- **True Backdrop Blur (Haze)**: Replaced simulated translucent background with the Haze backdrop blur engine (`HazeState` on `LazyColumn` via `hazeSource`, dock pill via `hazeChild`). Configured with 22dp blur radius, 72%+ dark tint (`#D11C1C1F`), 1dp hairline border (`#26FFFFFF`), subtle top edge highlight (`#14FFFFFF`), and near-opaque solid dark fallback below API 31.
- **Removed Scrims & Overlays**: Completely eliminated the 120dp bottom rectangular black gradient scrim and artificial nav bar padding boxes in `HomeScreen.kt`. Conversation items now scroll cleanly and continuously behind the real glass dock.

### 2. Search Tap Spring & Keyboard Transition (Item 2)
- **Unified Surface Container Transition**: Replaced the abrupt black modal pop-in with a container-style spring transition (`Motion.screenSpring()`, 200–300ms, alpha and `translationY`). The search field smoothly elevates to the header position while the home title and conversation list fade away.
- **Synchronized IME Animation**: Integrated WindowInsets IME animation with edge-to-edge `adjustResize`. The soft keyboard rises from the bottom in sync with the search bar spring. The destination uses the identical surface from frame one, eliminating black flashes.

### 3. Notification Launcher Icon & OEM Skin Badges (Item 3)
- **Resource Cache Invalidation**: Renamed launcher icon resources from `@mipmap/ic_launcher` to `@mipmap/ic_launcher_v2` across all densities (`mdpi`, `hdpi`, `xhdpi`, `xxhdpi`, `xxxhdpi`) and XML vector layers (`ic_launcher_v2.xml`, `ic_launcher_v2_round.xml`) to invalidate persistent OEM icon caches keyed by resource name.
- **MIUI / HyperOS Badge Override**: Added `applyXiaomiAppIcon()` in `MessageNotifier.kt` setting the proprietary `miui.appIcon` notification extra with an `Icon` created from `R.mipmap.ic_launcher_v2` on Xiaomi, Redmi, and Poco devices.
- **OEM Skin Documentation**: Documented findings in `docs/audit/OEM_NOTIFICATION_BEHAVIOUR.md`. Automated verification via `NotificationBuilderOutputTest`.

### 4. Back Swipe Latency & Predictive Back (Item 4)
- **Eliminated Delayed Pop**: Removed a redundant `BackHandler` in `ChatScreen.kt` that intercepted back events and delayed navigation until IME dismissal.
- **Deferred Database Writes**: Added no-op guards in `DraftStore.kt` on back-pop to prevent awaited DB writes or synchronous `markAsRead` calls from blocking the main thread during pop transitions.
- **Predictive Back Navigation**: Enabled `android:enableOnBackInvokedCallback="true"` in the Android Manifest, paired with smooth screen slide transitions in Navigation Compose.

### 5. Accessibility & Contrast Compliance (Item 5)
- **WCAG AA Compliance**: Fixed low-contrast text tokens across dark and light palettes. In `FixedDarkColorScheme` and `FixedLightColorScheme`, updated `outline` from low-alpha text to `TextMuted` (4.5:1+ contrast against background), and explicitly defined `error` and `errorContainer` colors.
- **Comprehensive Screen Audit**: Updated `TrashScreen.kt`, `DashboardScreen.kt`, `WhyFilteredScreen.kt`, `LoadFailedState.kt`, `NewMessageScreen.kt`, and `DriveBackupScreen.kt`. Ensured all subtitle, timestamp, and badge text meets or exceeds WCAG AA (>= 4.5:1 for body text, >= 3:1 for large text/icons). Verified via `FixedColorSchemesContrastTest.kt`.

### 6. Centered Transient Snackbars & Dialogs (Item 6)
- **Horizontal Centering**: Removed asymmetric end padding (formerly offset by 8dp for FAB clearance) in `HomeScreen.kt`. Wrapped transient snackbar content in `Modifier.wrapContentWidth(Alignment.CenterHorizontally)`.
- **Dock Clearance**: Elevated snackbar position with 96dp bottom padding in `AppTransientSnackbarHost` to float comfortably above the dock and centered horizontally across both LTR and RTL layouts.

### 7. Missed Touches Root Cause & Investigation (Item 7)
- **Root Cause Isolated**: Confirmed that the reported missed touches were caused by the 120dp bottom gradient box overlaying the conversation list, silently intercepting pointer input events on lower list items.
- **Verification & Resolution**: Removed the touch-intercepting overlay entirely. Added automated latency and touch dispatch test `TouchRegistrationTest.kt` verifying 100% tap registration with 0 dropped events and < 5ms touch-to-handler response.

### 8. Conversation List Row Height & Density (Item 8)
- **Adjusted Density**: Increased conversation row height to 82dp (from 72dp) in `Tokens.kt` (`Tokens.ChatRow.Height = 82.dp`), avatar container to 52dp (`Tokens.Avatar.Size = 52.dp`), avatar initial font size to 20sp, and vertical padding to 5dp.
- **Ergonomics**: Displays approximately 10 comfortable conversation rows per screen on standard 360dp-wide displays with generous touch targets.

### 9. Settings > Appearance & Restored In-App Brightness (Item 9)
- **Fixed Identity**: Removed obsolete "Theme" and "Accent color" selection rows from `SettingsScreen.kt`, solidifying the app's dark-mode brand identity.
- **Restored In-App Brightness**: Recovered the brightness controls from git history. Added a brightness slider with a "Use system brightness" toggle in `SettingsScreen.kt`. Backed by `ThemePreferences.kt` (`brightnessOverride`, `useSystemBrightness`) and wired into `MainActivity.kt` window attributes (`WindowManager.LayoutParams.screenBrightness`).
- **Updated Hub Summary**: Updated Appearance hub subtitle from "Dark theme, accents" to "Text size, brightness".

### 10. Settings Description Text Wrapping (Item 10)
- **Full Text Wrapping**: Removed `maxLines = 1` and `TextOverflow.Ellipsis` from subtitles in `SettingsComponents.kt` (`SettingsRow`), `SettingsHub.kt`, and `SettingsScreen.kt`.
- **Clear Explanations**: Revised subtitles under App Lock, Hide Message Previews, and Accessible Locked Space to explain clearly what each option does and why without truncation.

### 11. Archive Swipe Reveal Green Accent (Item 11)
- **Brand Green Accent**: Updated swipe reveal visuals in `HomeScreen.kt` `SwipeActionBackground` for `SwipeActions.ARCHIVE` to brand green (`#30D158` in dark mode, `#1E9A44` in light mode).

### 12. Summary Cards Conversation Toggle (Item 12)
- **Conversation-Level Overflow Toggle**: Moved the summary cards visibility master toggle from individual cards to the chat screen top-right 3-dot overflow menu. Displays "Hide summary cards" when visible, and "Show summary cards" when hidden.
- **Thread Persistence**: Per-conversation preferences are persisted via `MessageCards.setHiddenForConversation(conversationId, hidden)`. The individual card menu keeps only "Hide this summary". Global preference remains in Settings > Conversations. Verified via `SummaryCardWiringTest.kt`.

### X1. Trash Auto-Swipe Relabel & Opt-In Purge (Item X1)
- **Unknown Category Relabel**: Updated `MIGRATION_11_12` and added `relabelAutoSwipeToUnknown()` to relabel pre-2.5.1 auto-trashed messages as `"before 2.5.1 (unknown)"` (`TrashReason.UNKNOWN`).
- **Safe Batch Restoration**: Replaced generic auto-restore with a targeted "Restore all before 2.5.1" banner on `TrashScreen.kt`, with an explicit confirmation dialog stating the exact message count. Added per-item reason badges with high contrast.
- **Opt-In Purge**: Auto-purge is frozen by default. Messages remain in Trash indefinitely until deliberately deleted. Added an opt-in "Auto-purge Trash" toggle in Settings > Storage & cleanup (default OFF). Verified in `TrashReasonAndRestoreTest.kt`.

### X2. SMS Duplicate Intake & Brand Thread Merging (Item X2)
- **Deduplicated Intake**: Identified that fast broadcast intake (`onIncomingSms`) followed by telephony content provider sync (`indexHistorical`) created duplicate rows for the same message. Added brand-key and timestamp (±2000ms) matching in `MessageRepository.kt`. When a matching pending row is found, `smsId` and provider mapping are linked instead of inserting a duplicate row.
- **Circle Routing Normalization**: Implemented `canonicalBrandKey(rawAddress)` in `FriendlySenderNames.kt` to normalize Indian telecom circle prefixes (`VK-PhonePe`, `VM-PhonePe`, `AD-PhonePe` -> `"PHONEPE"`).
- **Thread Merging & Startup Deduplication**: Added `resolveThreadId` using normalized brand keys so circle variants share a single conversation thread. Added `deduplicateExistingMessages()` on repository initialization to clean pre-existing duplicate rows. Verified via `DuplicateOtpDeduplicationTest.kt`.

### X3. Settings Icon Colors (Item X3)
- **Color Discipline**: Enforced the rule that Yellow, Blue, and Red are reserved strictly for bottom dock navigation icons.
- **Neutral & Green Tinting**: Updated `SettingsHub.kt` and `SettingsComponents.kt` (`SettingsTileColors`) to use neutral and green tinted surfaces across all settings tiles and hubs.

### X4. Floating Action Button (FAB) Bottom Row Clearance (Item X4)
- **Increased Padding**: Updated `LazyColumn` bottom content padding in `HomeScreen.kt` to `WindowInsets.navigationBars.asPaddingValues().calculateBottomPadding() + 160.dp`.
- **Zero Overlap**: Guarantees that when scrolled to the end of the conversation list, the last conversation item sits comfortably 24dp above the FAB with zero text overlap.

### X5. Protection Engine: Crypto/Trading Solicitation Spam & Bank Alert Safety (Item X5)
- **Crypto & Trading Spam Filtering**: Expanded Rule 5 regex in `ProtectionEngine.kt` to detect unsolicited trading platforms, bots, tips, multibagger calls, and NFT solicitations (including MATLIA, NSETrade, Sigilum) from unknown senders, routing them to `Category.SPAM`.
- **Absolute Bank & OTP Protection**: Evaluated Stage 2 protected patterns prior to spam heuristics. Updated `protect-bank-txn` regex in `patterns.json` to handle both `"debited ... a/c"` and `"a/c ... debited"` phrasing. Legitimate bank debit alerts and OTPs mentioning crypto exchanges or trading platforms remain strictly protected in `Category.TRANSACTIONS` and `Category.INBOX`. Verified via `MisfilingRulesTest.kt`.
